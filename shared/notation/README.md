# Notation

| Symbol | Meaning |
|---|---|
| $K_X$ | Canonical divisor class of the surface $X$ |
| $K_X^2$ | Self-intersection number of the canonical class |
| $p_g(X)$ | Geometric genus, $h^0(X,K_X)$ |
| $q(X)$ | Irregularity, $h^1(X,\mathcal O_X)$ |
| $e(X)=c_2(X)$ | Topological Euler characteristic, the degree of the second Chern class |
| $\chi(\mathcal O_X)$ | Holomorphic Euler characteristic |
| $b_i(X)$ | Dimension of $H_i(X,\mathbb Q)$ over $\mathbb Q$ |
| $\pi_1(X)$ | Topological fundamental group |
| $H_1(X,\mathbb Z)$ | First integral homology, the abelianization of $\pi_1(X)$ |
| $\operatorname{Aut}(X)$ | Biholomorphic automorphism group of $X$ |
| $\mathbb B^2$, $\mathbb D$ | Unit ball in $\mathbb C^2$ and unit disk in $\mathbb C$, respectively |
