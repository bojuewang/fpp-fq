# Fake projective planes

This branch studies explicit models of fake projective planes. Start with the [surface definitions](../shared/definitions/surfaces.md) and the [surface registry](database/registry.json). Each registry ID identifies one surface up to the equivalence specified in its record. Distinguish a complex surface from its conjugate when interpreting a classification label.

| Question | Where to work |
|---|---|
| Which surface does a label identify? | [Classification](classification/), [database](database/), [surface records](surfaces/) |
| Which equations and symmetries describe it? | [Equations](equations/), [groups](groups/), [automorphisms](automorphisms/) |
| How are different quotients related? | [Coverings](coverings/), [commensurability](commensurability/) |
| What supports the claim? | [Experiments](experiments/), [verification](verification/), [literature](literature/) |

Add a surface using the [data protocol](../protocols/data.md). Place reusable engine code in the [computational workspace](../computational/).
