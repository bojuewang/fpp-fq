# Identifiers and file names

Choose a stable ID with the prefix `fpp-` or `fq-` followed by a descriptive lowercase ASCII slug. Use single hyphens to separate nonempty alphanumeric components. The directory basename and the `surface_id` in its metadata must agree. A registry holds each ID once in lexicographic order.

Preserve labels from the literature exactly in `classification_id` and `alternative_ids`, together with a source identifier. Record how the source label identifies this surface. Document changes of identification in the surface README and research history. Avoid reusing a retired ID for a different surface.

Use descriptive file names, `.m` for Magma, `.wl` or `.wls` for Wolfram Language, `.nb` for notebooks and `.json` for portable metadata.
