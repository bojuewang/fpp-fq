# Using notation

Consult the [symbol table](../shared/notation/README.md) before introducing a symbol. Define local coordinates, generators, base fields, actions and composition order at first use. State the basis and orientation of any matrix and the variable and monomial order of every polynomial encoding.

When transcribing a paper, retain the author's labels and describe the translation to local conventions. Keep the topological Euler characteristic $e(X)$ and the holomorphic Euler characteristic $\chi(\mathcal O_X)$ explicit.
