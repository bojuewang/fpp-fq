# Fake quadrics

This branch studies explicit models of fake quadrics. Start with the [surface definitions](../shared/definitions/surfaces.md) and the [surface registry](database/registry.json). Record the evidence for a bidisk presentation before using it to deduce lattice or covering properties.

| Question | Where to work |
|---|---|
| Which numerical or geometric class contains the surface? | [Classification](classification/), [database](database/), [surface records](surfaces/) |
| Which equations and symmetries describe it? | [Equations](equations/), [groups](groups/), [automorphisms](automorphisms/) |
| Which covers and commensurability relations are established? | [Coverings](coverings/), [commensurability](commensurability/) |
| What supports the claim? | [Experiments](experiments/), [verification](verification/), [literature](literature/) |

Add a surface using the [data protocol](../protocols/data.md). Place reusable engine code in the [computational workspace](../computational/).
