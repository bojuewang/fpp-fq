# Research roadmap

The FPP and FQ branches can advance independently. Each milestone below names an artifact that another researcher can inspect or rerun.

| Milestone | Evidence for completion |
| --- | --- |
| Identify a first surface in each family | A primary source, its original designation, the repository identifier, and a registry entry linked to schema-conforming metadata. |
| Reconstruct an explicit model | The source equations, coefficient field and presentation, ambient coordinates, and a script that reconstructs the model in Magma or Mathematica. |
| Verify a geometric property | A precise claim with hypotheses, an exact computation or proof, and a record of how to check it independently. |
| Describe a group action or a covering | The action on coordinates or the maps defining the cover, together with evidence for the stated relation, degree, or group. |
| Compare models across records | A report identifying which properties are proved, which have computational support, and which depend on unresolved assumptions. |

For a fake quadric, establish the universal cover independently whenever a milestone uses bidisk uniformization. For either family, retain the source's equivalence relation when comparing classifications or counting surfaces. [FPP branch](fpp/) · [FQ branch](fq/) · [Research protocol](protocols/research.md)
